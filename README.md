# CISC101-Group22-PaperSummarizer
By Antony Li, Yoshi Kosugi, Sena Nishimura

This repository holds our CISC 101 group project: a little modular system that reads section text from a research paper and produces clean, evidence-based summaries.

Files:

system_prompt.md – the full system instructions

modules/01_intake.md – input handling and section checks

modules/02_section_loop.md – per-section summarization

modules/03_guardrails.md – strict evidence rules and warnings

modules/04_rendering.md – final output assembly

modules/05_student_module_a.md – key contributions module

modules/06_student_module_b.md – citation extractor

Features:

short or detailed summaries

expert and layperson versions

unified final summary

mini-glossary

warnings for missing, empty, or short sections

no hallucinated content

A small, tidy summarizer built with modular prompting and gentle little guardrails.
