Student module A: Key contributions
Purpose
Extract and list the paper’s core contributions using only the provided text.

Inputs
Section texts: Prefer Abstract, Introduction, Results, Discussion, Conclusion, and Contributions (if present).

Procedure
Scan for contribution statements:

Phrases: “We propose…,” “Our main contribution…,” “This work demonstrates…,” “We show…”.

Evidence-only: Quote or paraphrase strictly from provided text.

Summarize contributions:

Create 3–7 bullets with bold lead-ins and concise wording.

Each bullet ≤30 words.

If unclear or absent: “Not stated in the provided text.”

Consistency:

Use canonical terms established in Intake.

Output
“Key contributions” section:

3–7 bullets summarizing contributions.

Warnings: If contributions not found or sections are short/missing.
